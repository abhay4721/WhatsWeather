# 🌦️ WhatsWeather

A beautiful, fast, and privacy-friendly weather app powered by the [Open-Meteo](https://open-meteo.com/) open source API.  
Enjoy dynamic Lottie animations, Material 3 theming, home screen widgets, and blazing fast weather updates.

---

## ✨ Features

- **Current, hourly, and daily weather**
- **Live weather icons (Lottie) with day/night and theme support**
- **Home screen widget**
- **Favorites management**
- **Location-based weather fetching**
- **Modern Material 3 UI**
- **Privacy-first: no ads, no tracking**
- **Open-Meteo Open Source API**  
- Fast, reliable, and free weather data with privacy in mind.
- **Lottie Animations**  
- Stunning, animated weather icons for every condition, day and night, light and dark.
- **Material 3 (Material You) Support**  
- Dynamic theming that adapts to your device and preference.
- **Faster Weather Loading**  
- Instantly fetch the latest weather wherever you are.
- **Smooth UI Transitions**  
- Enjoy a modern, polished interface experience.
- **Reliable Storage of Favorites & Settings**

---

## 🛠️ Tech Stack

- **Flutter** (cross-platform)
- **Open-Meteo API** for weather data
- **Lottie** for weather animations
- **Material 3** (Material You) theming
- **HomeWidget** for Android widgets
